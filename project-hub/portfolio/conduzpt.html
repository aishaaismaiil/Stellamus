Aprender também é poder ensaiar

O ConduzPT explora a ideia de praticar observação e decisões num contexto urbano, antes de enfrentar essas situações na estrada. Chelas é o contexto dos primeiros protótipos.

Um laboratório, ainda longe de um simulador completo

Existem experiências web e uma experiência separada em Godot. O pacote disponível nesta página é o protótipo Chelas 02 identificado no histórico de desenvolvimento de outubro de 2026.

Os dados do mapa não garantem a localização atual de sinais, passadeiras, obras ou condições de circulação. Este protótipo não substitui aulas de condução, não é homologado para formação e não deve ser usado durante a condução.

Próximos passos

  • Melhorar a representação das ruas e dos elementos de trânsito.
  • Verificar os cenários com instrutores e dados adequados.
  • Testar a clareza das instruções e do feedback.

O ficheiro para descarregar é um projeto para Godot, não um jogo que abre diretamente no navegador. Inclui instruções e materiais dessa versão. Precisas de abrir o projeto no Godot para o experimentar.
