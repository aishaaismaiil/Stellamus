# SENSORA Social

Investigação e proposta de cocriação sobre participação social de pessoas surdocegas. Não é uma tecnologia acessível validada nem uma intervenção inédita demonstrada. O site apresenta a hipótese, os limites, as fontes e os próximos passos. Não recolhe diagnósticos nem dados de participantes.

A base de dados regista este projeto e suporta feedback autenticado. A interface não envia dados automaticamente.
